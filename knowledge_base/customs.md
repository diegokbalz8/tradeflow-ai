# TradeFlow Customs Guide

## Import documentation

Before an import shipment can be processed, the importer should verify that the required documentation is available.

Common documents include:

- Commercial invoice
- Packing list
- Bill of lading or air waybill
- Import permits when applicable
- Certificate of origin when applicable

## Commercial invoice

The commercial invoice normally contains information about the buyer, seller, merchandise, quantity, value, currency, and country of origin.

The information should be consistent with the other shipment documents.

## Customs documentation issues

If customs identifies a discrepancy in the documentation, the importer should review the affected documents and contact the customs broker or logistics provider handling the shipment.

If the discrepancy cannot be resolved using the available documentation, the case should be escalated to a customs specialist.

## Shipment delays

When a shipment is delayed during the customs process, the first steps are:

1. Verify the current shipment status.
2. Check whether customs has requested additional documentation.
3. Verify that the submitted documentation is complete.
4. Contact the customs broker or logistics provider for additional information.
5. Escalate the case to a customs specialist if the reason for the delay remains unclear.
